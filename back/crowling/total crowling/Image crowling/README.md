# Image Crowling

Refines raw pages from total crowling into image-only records.

Output fields include:

- `source_url`
- `page_url`
- `title`
- `alt`
- `caption`
- `width`
- `height`
- `extension`
- `fingerprint`

Run:

```powershell
python "back/crowling/total crowling/Image crowling/cli.py"
```
