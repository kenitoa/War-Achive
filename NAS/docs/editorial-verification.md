# NAS 단독 파이프라인 검증 기록

검증일: 2026-11-05. 현재 운영 서버·운영 DB·기존 PC 자료는 사용하지 않았다. 변경은 NAS 폴더 내부에 한정하며 외부 발행·배포는 실행하지 않았다.

핵심 통합 검증은 실제 수집 응답 형태의 테스트 입력을 사용해 수집·정규화·분석·승인·발행·백업/복원까지 연결한다. 중복 생성/발행, 예약 시간, 다중 작업자, 임대 만료, 저장소 오류 5회 제한·재시도, 문단 근거 검증, 오래된 개정 충돌, CSRF/역할 제한, XSS 이스케이프, 자료 변경·미확인·철회 시 즉시 비공개를 확인했다. 테스트 대체 응답을 운영 수집 성공으로 표현하지 않는다.

Fastify의 기존 로깅 옵션 폐기 예정 경고와 관리자 빌드의 Zod 주석 제거 경고가 있으나 검사는 통과했다.

## 미검증 범위

이 환경에는 Docker CLI/Engine이 없어 이미지 빌드, 이미지 내 PostgreSQL 17 도구 라이브러리, Linux 컨테이너 도구 실행, 실제 Compose 시작, 실물 NAS 파일 시스템·재부팅·HTTPS 역방향 프록시는 실행 검증하지 못했다. 이를 가동 성공으로 간주하지 않는다.

`sh install.sh`는 대상 NAS에서 테스트 포함 이미지 빌드와 preflight, DB 마이그레이션, worker heartbeat 및 gateway 준비 확인을 수행한다. 필수 단계 실패 시 설치 성공을 표시하지 않는다. 이 절차는 해당 환경에서 실행된 뒤에야 설치 검증 증거가 된다.

산출물은 `node scripts/package-nas.mjs`로 생성한다. 실제 `.env`, DB·원본·릴리스·node_modules·빌드 출력은 제외하며 파일별 manifest와 압축 파일 SHA256을 함께 제공한다. 실사용 비밀값은 대상 NAS에서 생성한다.
