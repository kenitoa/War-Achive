# 전쟁 아카이브 · NAS 관리자

NAS 백엔드와 같은 출처의 `/admin/`에서 제공되는 비공개 운영 화면입니다. 실제 API에서 가져온 기록만 표시합니다.

```powershell
npm.cmd ci
npm.cmd run dev
```

개발 서버는 `/api` 요청을 NAS의 `.env`의 `ADMIN_PORT`에 해당하는 로컬 API로 전달합니다. 개발용 Vite 주소(기본 `http://127.0.0.1:5173`)를 NAS의 `ALLOWED_ORIGINS`에 명시해야 인증 변경 요청을 허용합니다. 운영에서는 `npm.cmd run build` 결과인 `dist/`를 NAS 백엔드가 제공하며, 정적 폴더를 외부 공개 웹사이트에 복사하지 않습니다.

## 인증

관리자 토큰을 `POST /api/v1/session`에 전달하고, HttpOnly 세션 쿠키와 메모리의 CSRF 토큰을 사용합니다. 브라우저 저장소에 토큰을 보관하지 않습니다. 변경 요청은 `X-CSRF-Token` 헤더를 사용합니다. 관리자 접근 네트워크와 HTTPS는 NAS 배포 문서에 따라 설정합니다.

## 기능

- 실제 운영 집계, 최근 작업과 출처 상태
- Library of Congress / Wikimedia Commons 수집 출처 등록·편집·즉시 수집
- 자료 상세·출처 확인·메타데이터 편집·검수·승인·반려·철회
- 출처 재확인으로 발견한 비공개 변경 후보 비교, 편집칸으로 명시적 반영, 이전 개정 읽기
- 권리 근거를 기록한 원본 파일 등록, 보존 파일·파생물 목록, 자료 제작 작업 요청
- 작업 이력과 실패 작업 재시도
- 로컬 공개본 생성과 GitHub 전달 요청, 실제 처리 상태 표시
- 감사 기록, 정정·자료 제안의 내부 처리
- 비밀값을 제외한 설정 상태와 메타데이터 백업 다운로드

목록은 페이지당 최대 100건을 조회하며 이전·다음으로 이동합니다. 전쟁·사건·인물·조직·장소·장비·주제별 모음·주장과 수치는 사전 메뉴에서 편집합니다. 로컬 공개본 생성은 외부 배포 완료를 의미하지 않습니다. 백업 다운로드는 원본 파일 백업을 대체하지 않습니다.

`src/generated-contract.ts`, `src/generated-models.ts`는 백엔드 계약에서 동기화합니다. 공유 API 타입을 직접 중복 선언하지 않습니다.

자료 상세의 원본 등록은 최대 16MiB의 텍스트·PDF·JPEG·PNG·WebP·WAV·MP4를 받습니다. 실제 허용 형식과 서명 검증은 서버가 최종 판단합니다. 보존·처리·공개 권리의 근거를 기록해야 하며, 원본은 비공개 보존합니다. 공개 미디어 저장소가 연결된 환경에서만 파생물 공개를 선택할 수 있습니다. 제작 요청의 접수와 판독·미리보기 생성 성공은 별개이며 작업 이력에서 확인합니다.

편집자 역할은 원본을 비공개로 등록합니다. 검수자·관리자는 기존 파일의 공개 권리 검토에서 근거를 기록하고 파생물 공개를 허용하거나 취소합니다. 관리자는 원본 등록과 공개 권리 결정을 함께 수행할 수 있습니다. UI는 세션 역할에 따라 원본 등록과 공개 선택을 제한하며, 실제 권한 경계는 API가 다시 검증합니다.

출처 변경 후보는 현재 편집본과 비교한 뒤 제목·설명·날짜·출처를 편집칸에 가져올 수 있습니다. 이 동작 자체는 저장·공개를 수행하지 않습니다. 기존 개정 번호를 사용한 저장으로 충돌을 확인하고, 그 후 별도로 공개 검토합니다. 판독·번역·관계·권리 입력은 자동으로 덮어쓰지 않습니다. 이전 개정은 읽기 전용이며 자동 롤백 기능은 제공하지 않습니다.

## 검증

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run test
npm.cmd run build
npm.cmd audit --omit=dev
```

통합 NAS 서버 실행 후 `npm.cmd run test:browser`로 Edge의 데스크톱·모바일 화면과 실제 세션 인증·전체 메뉴 조회를 검사합니다. 접속 포트는 NAS의 `.env`의 `ADMIN_PORT`를 따르며 누락 시 4310을 사용합니다. `ADMIN_BASE_URL`, `BROWSER_EXECUTABLE`, 필요한 경우 `ADMIN_OTP`로 환경을 지정합니다. 토큰은 환경 또는 NAS의 `.env`에서 읽으며 출력하지 않습니다. 이 검사는 로그인·로그아웃 외에는 자료를 변경하지 않고, 화면은 Git 제외 경로 `NAS/artifacts/admin/`에 저장합니다.

자료가 있는 환경에서는 실제 자료·보존 파일·이전 개정을 조회하고, 업로드 폼에는 파일을 선택만 하며 전송하지 않습니다. 출처 변경 후보를 편집칸에 가져오는 분기는 브라우저의 한 GET 응답에만 격리된 입력을 주입해 검사합니다. 이 후보는 서버에 저장하거나 발행하지 않으며 실제 응답으로 찍은 스크린샷에도 포함하지 않습니다. 검사 출력은 실제 API 조회와 이 격리된 UI 검사를 구분합니다.
